# boards/

The Break the Line adversarial catch board lands here:

- `BREAK_THE_LINE_BOARD.json` — machine-readable aggregate (per-control,
  per-model catch rates over N runs)
- `BREAK_THE_LINE_BOARD.md` — the human-readable rendering

Both are generated by the factory's board generator
(`scripts/build_break_the_line_board.py` in the private repo) from per-run
adversarial reports, and published here by the founder. Every number is an
aggregate over recorded runs — the raw injected payloads and gate
internals stay in the private evidence vault per `../PROOF_BOUNDARY.md`.

## boards/sqscm/

The public SQSCM factory-health board (Safety, Quality, Service, Cost,
Maintainability with First Catch Yield as the primary Quality gauge).
Structure reserved; artifacts land as the SQSCM board generator ships.
